# IFH Business Copilot

مساحة عمل للمؤسسين وفرق الأعمال. اختر مسارًا، جهّز معلومات مشروعك، واستخدم قالبًا ينتج قرارًا أوليًا وخطوة تالية واضحة.

<Note>القوالب متاحة الآن. المحادثة الذكية تتطلب تفعيل مساعد Mintlify والتحقق من تشغيله؛ لم تُفعّل ضمن هذا التحديث.</Note>

## طوّر فكرة ناشئة

العميل، المشكلة، البدائل، عرض القيمة، ونطاق المنتج الأول.

```text
السوق: [ ]. العميل: [ ]. المشكلة: [ ]. المرحلة: [ ]. الميزانية والعملة: [ ]. استخدم إطار البوابة لتحديد افتراضات الفكرة، واقترح تجربة تحقق، ونطاق منتج أول وخطة 30 يومًا. اسأل عن المعلومات الناقصة ولا تفترض وجود طلب مثبت.
```

## صمّم نموذج الإيرادات

قيمة الاشتراك، تكلفة الخدمة، وهامش المساهمة ونقطة التعادل.

```text
المنتج: [ ]. السعر لكل عميل شهريًا: [ ]. التكلفة المتغيرة لكل عميل: [ ]. التكاليف الثابتة شهريًا: [ ]. العملة: [ ]. احسب هامش المساهمة ونقطة التعادل، ثم قدم سيناريوهات بافتراضات معلنة. لا تعتبر التقديرات أرباحًا مضمونة.
```

## اختر مسار التقنية

متطلبات المنتج، بدائل البناء والشراء، وأسئلة تقييم المزود.

```text
المنتج: [ ]. السوق: [ ]. عدد المستخدمين المتوقع: [ ]. البيانات والتكاملات المطلوبة: [ ]. الميزانية والمدة: [ ]. قارن البناء الداخلي والشراء من مزود والتكامل مع شريك. ميّز المعلومات المؤكدة عن الأسئلة التي تتطلب تحققًا رسميًا.
```

## جهّز ملف الشراكة

عرض قيمة، نطاق تجربة، مسؤوليات، ورسالة تواصل أولية.

```text
المشروع: [ ]. العميل المستهدف: [ ]. نوع الشريك المطلوب: [ ]. القيمة التي نقدمها: [ ]. ما نحتاجه: [ ]. صغ ملخص شراكة ونطاق تجربة ومؤشرات نجاح ومسودة رسالة. لا تدّع وجود اتفاق ولا ترسل الرسالة.
```

## كيف يبدو المخرج المفيد؟

1. ملخص الاحتياج والمعلومات الناقصة
2. الخيارات ومبرر الاختيار الأولي
3. الافتراضات والمصادر وما يحتاج تحققًا
4. خطة 30 يومًا: مهمة، مسؤول مقترح، ومقياس نجاح
5. الخطوة التالية أو سؤال واحد يحسم القرار

## مثال حسابي: اشتراك لخدمة أعمال

مثال تعليمي بافتراضات، وليس توقعًا لمشروعك: سعر الاشتراك 300 درهم شهريًا، والتكلفة المتغيرة 100 درهم للعميل، والتكاليف الثابتة 6,000 درهم شهريًا. هامش المساهمة = 300 − 100 = 200 درهم. نقطة التعادل = 6,000 ÷ 200 = 30 عميلًا. عند 20 عميلًا تكون النتيجة −2,000 درهم، وعند 40 عميلًا +2,000 درهم، قبل الضرائب والتكاليف غير المدرجة. يجب اختبار تكلفة اكتساب العميل، والاحتفاظ به، والتحصيل قبل اعتماد النموذج.

## خطة تحقق أولية خلال 30 يومًا

| المرحلة | المهمة |
| --- | --- |
| الأسبوع الأول | قابل عملاء محتملين، وسجل المشكلة والبديل الحالي ودليل الاستعداد للدفع. |
| الأسبوع الثاني | اختبر عرض القيمة بسعر واضح ونموذج أولي محدود. |
| الأسبوع الثالث | قارن خيارات التقنية واجمع عروضًا رسمية ومتطلبات الشركاء. |
| الأسبوع الرابع | راجع النتائج واتخذ قرار الاستمرار أو تعديل الفكرة مع معيار نجاح محدد. |
