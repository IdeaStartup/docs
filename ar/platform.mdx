## بنية مقترحة على مراحل

| المكون | دوره المقترح | الحالة في المشروع |
| --- | --- | --- |
| Mintlify | الموقع والأدلة ومساعد معرفة المحتوى عند تفعيله | البوابة منشورة؛ تشغيل المساعد لم يُتحقق منه |
| Cloudflare Workers | تشغيل تطبيق الطلبات وواجهات الربط | مخطط؛ لم يُنشر تطبيق تشغيلي |
| Cloudflare Agents | سياق الطلب والتفاعل واستدعاء الأدوات | مخطط |
| Workflows | الاستكمال واعتماد الموظف واستئناف الخطوات | مخطط |
| قاعدة بيانات وتخزين مستندات | ملفات المؤسسة وحالات الطلب وسجل الإجراءات | يتطلب تصميم الصلاحيات والاحتفاظ |
| نظام المؤسسة الحالي | استقبال الملفات وإرجاع أرقام الطلبات وحالاتها | يحتاج تقييم الواجهات واتفاق الربط |
| Mambu | تكامل مصرفي محتمل لدى مؤسسة تستخدمه | قيد التقييم؛ لا شراكة أو ربط قائم |

## كيف يمر الطلب؟

1. يتحقق التطبيق من البيانات وصلاحية الوصول.
2. تُفهرس المستندات ويُفحص اكتمالها مقابل قائمة معتمدة.
3. يعرض المساعد الملخص ومصدر كل ملاحظة ونقاط عدم اليقين.
4. يراجع الموظف النتائج ويعتمد مسودة الاستكمال أو الإحالة.
5. يسجل التطبيق الإجراء والوقت، ويستقبل حالة الطلب من النظام المرتبط إن أتيح.

وجود مستند لا يثبت أصالته. يُفصل فحص الاكتمال عن التحقق من الأصالة والتقييم والقرار النهائي.

## خيارات الربط

نبدأ بتسليم ملف منظم عبر قناة معتمدة، ثم API أو تبادل ملفات آمن إن توفر. غالبًا يكون الربط الأول بنظام إدارة الطلبات أو CRM. لا يُرسل طلب إلى أي مزود مالي قبل الاتفاق وضبط الموافقات والصلاحيات.

## الإعداد قبل التشغيل

صلاحيات مستقلة لكل مؤسسة ومستخدم، تخزين خاص، أسرار الربط على الخادم، قواعد منع تكرار الطلب، معالجة الفشل، وسجل إجراءات. تُحدد سياسة الاحتفاظ والحذف ومتطلبات الاستضافة وتداول البيانات مع العميل. هذه متطلبات تنفيذ وليست ضوابط مثبتة في البوابة الحالية.

## موارد المزودين

- [Cloudflare Workers](https://developers.cloudflare.com/workers/): بيئة تشغيل التطبيقات وواجهات الربط.
- [Cloudflare Agents](https://developers.cloudflare.com/agents/): بناء المساعدين ذوي السياق المستمر.
- [Cloudflare Workflows](https://developers.cloudflare.com/workflows/): خطوات متعددة وانتظار الموافقات.
- [Mintlify Assistant](https://www.mintlify.com/docs/assistant): مساعد يعتمد على المحتوى المنشور.
- [Mambu API](https://docs.mambu.com/docs/mambu-apis/): مرجع لتقييم التكامل المصرفي.

خطة Cloudflare المجانية لا تعني أن التطبيق والنماذج والتخزين بلا تكلفة. قبول Mintlify Startups أو Mambu Partners غير مؤكد ولا يدخل ضمن وعودنا للعميل.
