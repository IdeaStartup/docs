<Info>هذه نسخة أولية للمراجعة. قناة التواصل التجارية لم تُعتمد بعد؛ لا يوجد نموذج إرسال أو استقبال طلبات فعلي في هذه الصفحة.</Info>

## ملخص نحتاجه للمناقشة

- الاسم والشركة والدولة.
- صفتك: مؤسس، مؤسسة أو مزود تقنية.
- مرحلة المشروع: فكرة، نموذج أولي، منتج قائم أو توسع.
- المشكلة والمستخدم المستهدف.
- الخدمة المطلوبة: منتج، ذكاء اصطناعي، تكامل، توثيق أو شراكة.
- الميزانية والموعد المتوقع، إن كانا محددين.

## قبل مشاركة البيانات

يكفي وصف الاحتياج؛ لا ترسل كلمات مرور أو بيانات حسابات أو مفاتيح API أو مستندات حساسة.

## الخطوة التالية

بعد اعتماد اسم الشركة وبريدها، تُضاف قناة اتصال واضحة وسياسة خصوصية مطابقة لطريقة استقبال الطلبات.
