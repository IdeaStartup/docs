هذا دليل تخطيط، وليس توثيقًا لواجهة API تشغيلية خاصة بالشركة.

<Steps>
  <Step title="حدد حالة الاستخدام">وثّق المستخدم والوظائف الأساسية والحجم المتوقع والنتيجة المطلوبة.</Step>
  <Step title="حدد البيانات والصلاحيات">وضح مصادر البيانات والموافقات والمعلومات الضرورية وحدود الاحتفاظ.</Step>
  <Step title="اختر المزود">تحقق من البلد والبنوك والعملات والأسعار والمتطلبات والتزامات الدعم.</Step>
  <Step title="نفذ تجربة محدودة">ابدأ ببيئة اختبار وبيانات اصطناعية، ثم اختبر حالات النجاح والفشل.</Step>
  <Step title="اتفق على التشغيل">حدد مسؤولية المراقبة والأخطاء والتحديثات والدعم قبل الإطلاق.</Step>
</Steps>

## مثال توضيحي لطلب مشروع

```json
{
  "project_type": "transaction_insights",
  "market": "UAE",
  "stage": "discovery",
  "data_source": "to_be_confirmed",
  "success_measure": "reduce_manual_reporting_time"
}
```

هذا نموذج معلومات وليس طلبًا إلى API قائم. تُحدد واجهات الربط الفعلية بعد اعتماد المزود والعقد.
