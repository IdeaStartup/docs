# Documentation project instructions

## Project
Mintlify introductory and technical portal for fintech, AI and startup services in the UAE. The owner confirmed the company name Innovation Finance Hub and contact email osak9887@gmail.com. Content is in Arabic and English; configuration is docs.json.

## Style
Use concise active language and specific deliverables. Keep both languages aligned. Arabic pages use appropriate right-to-left text; code examples remain left-to-right.

## Boundaries
Do not invent company registration details, contact addresses, partnerships, certifications, customer metrics, prices or regulatory permissions. Identify proposed services and planning examples accurately. Do not describe a live API, AI assistant, remittance flow or enquiry submission unless implemented and verified.

## Validation
Check navigation paths and local links, MDX frontmatter and components, then use Mintlify preview when available. Preserve unrelated repository files. Changes go on a feature branch for review before merging into the deployed branch.
